# GRAIN 1.2 — Rust

Дополнение к [ядру стандарта](README.md). Ядро переносится дословно: словарь глаголов, единицы измерения, префиксы булевых, теги комментариев — те же.

## Имена

`snake_case` для функций и переменных, `PascalCase` для типов, `SCREAMING_SNAKE_CASE` для констант — как в самом Rust. GRAIN добавляет словарь:

```rust
fn find_track(id: &TrackId) -> Option<Track>      // find → Option
fn get_track(id: &TrackId) -> Track               // get → значение или panic на инварианте
fn read_manifest(path: &Path) -> Result<Manifest> // read → I/O
fn derive_duration_sec(track: &Track) -> u32      // derive → чисто
```

`Option` у `find_*` и его отсутствие у `get_*` — тот же контракт, что в TypeScript, только выраженный системой типов, а не аннотацией.

**`new` разрешён** как идиоматичный конструктор Rust — это `make` под именем, которого ждёт язык. Имена, продиктованные трейтами (`from`, `into`, `fmt`, `drop`, `clone`, `next`, `poll`, `serialize`, `deserialize`), остаются как есть.

**Единицы обязательны и здесь:** `timeout_ms: u64`, `size_bytes: usize`, `price_cents: i64`. Тип `u64` говорит о разрядности, но ничего не говорит о смысле числа.

## Отказы

| Ситуация | Инструмент |
|---|---|
| Ожидаемый отказ | `Result<T, DomainError>`, где `DomainError` несёт код `домен.предмет.причина` |
| Нарушенный инвариант | `panic!` / `expect` с сообщением, объясняющим инвариант |
| Отсутствие как норма | `Option<T>` |

**`unwrap()` в продакшн-коде запрещён.** В тестах — разрешён. Вместо `unwrap()` — `expect("инвариант, который нарушен")`: паника без объяснения не расследуется.

`let _ = fallible();` — то же, что пустой `catch`: отказ выброшен в тишину. Либо `?`, либо явная обработка.

## Модули и файлы

Роль выражается именем модуля, а не суффиксом файла:

```
src/track/mod.rs        публичный вход домена
src/track/store.rs      доступ к БД/файлам
src/track/policy.rs     правила, чисто
src/track/shape.rs      типы домена
```

Запрещены `utils.rs`, `helpers.rs`, `common.rs`, `misc.rs` и одноимённые каталоги — как и в TypeScript. Чистые вычисления живут в модуле своего домена.

## Форма

Пределы ядра действуют: вложенность 2, аргументов 3, 40 строк на функцию, 400 на файл. Ранний выход через `?`, `return`, `let ... else` — вместо лестницы `if let`.

```rust
let Some(track) = find_track(id) else {
    return Err(DomainError::new("music.track.missing"));
};
```

`clippy` с `-D warnings` — обязательная часть сборки; GRAIN его не заменяет, а дополняет там, где clippy молчит: имена, единицы, комментарии.
